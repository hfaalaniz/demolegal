# ⚖️ Abogados & Asociados – Estudio Jurídico

Sitio web institucional para estudio jurídico ubicado en Córdoba, Argentina. Desarrollado con HTML, CSS y JavaScript vanilla, sin dependencias externas ni frameworks.

## 🌐 Demo

> [Ver sitio en vivo](https://hfaalaniz.github.io/demolegal/)

---

## 📋 Descripción

Landing page profesional para estudio de abogados con las siguientes secciones:

- **Hero** – Presentación del estudio con identidad visual
- **¿Qué hacemos?** – Áreas de práctica con detalle interactivo
- **Agenda Abierta** – Formulario de reserva de turno + contacto directo por WhatsApp
- **Valores** – Pilares del estudio
- **Footer** – Datos de contacto, dirección y redes sociales

## 🗂️ Estructura del proyecto

```
legaldemo1/
├── index.html       # Estructura principal
├── styles.css       # Estilos y diseño responsivo
├── app.js           # Lógica e interactividad
└── icons.svg        # Sprite SVG con todos los íconos
```

## ✨ Características

- Diseño responsivo (mobile-first)
- Navegación con scroll suave y navbar sticky
- Áreas de práctica con panel de detalle interactivo
- Botones directos a WhatsApp por cada abogado
- Formulario de turno con validación del lado del cliente
- Sin frameworks ni dependencias externas

## 🛠️ Tecnologías

- HTML5 semántico
- CSS3 (variables, grid, flexbox, animaciones)
- JavaScript vanilla (ES6+)
- Google Fonts (Cormorant Garamond + Montserrat)
- SVG sprites
